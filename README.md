# RMC Web Solutions — React + Node (V41.8)

Razvojni projekat iz **V41.7.1** proširen je na **72/72 osnovna scenarija**. Funkcionalni, vizuelni i kontaktni paritet sa V39.5 još imaju izdvojene zadatke koji su jasno navedeni u **`PROJECT_STATUS.md`** i mašinski čitljivo opisani u `server/src/data/parity-matrix-v418.json`.

- `npm run dev`: lokalni React/Vite + Node.
- `npm test`: postojeće Commerce/Booking/Hybrid regresije i nova V41.8 provera svih 72 scenarija.
- `npm run build`: lokalni React production build (obavezno na Windows-u).
- `node scripts/smoke-v418.mjs`: kada lokalni server radi, provera verzije, Advisora i 10 sektorskih prikaza.

Preview i ZIP koriste isti server-rendered HTML. V41.8 sadrži 55+ originalnih V39.5 fotografija sa SHA-256 evidencijom porekla. Delatnosti koje nemaju vlastite izvorne fotografije prikazuju uredne tekstualne kartice umesto izmišljenih fotografija.

**Granica DEMO-a:** termini, narudžbine i upiti pripremaju poruke za Kopiranje/Viber/WhatsApp; ne potvrđuju raspoloživost, ne naplaćuju i ne šalju automatski podatke na server prodavca. Globalni poslovni podaci, DEMO oznaka i pravi kanali dostave pripadaju dogovorenim V42/V43 modulima. Vizuelni paritet pet stilova pripada V41.9.

Referentni V39.5, GitHub `main`, Render i Webglobe ne menjaju se lokalnom V41.8 zakrpom.
