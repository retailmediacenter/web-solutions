# RMC Web Solutions — Showcase

Repozitorijum demonstracionih klijentskih sajtova. Početna galerija: `index.html`. Prvi projekat: `clients/nina22/`.

**Važno:** Ovaj repozitorijum **nije** kopija Web Solutions generatora. NINA 22 V3.3 je zaseban dizajn / statičan demo sa pripremljenim konfiguracijama, a povezivanje sa postojećim Editorom radiće se kada njegova struktura bude stabilna.

Za zamenu fotografija, proveru funkcionalnosti i pripremu **SEO za pravi klijentski domen** videti **jedini glavni dokument**: `clients/nina22/README.md`.

**GitHub Pages:** upload celog sadržaja ovog paketa u root repozitorijuma; `Settings → Pages → main → /(root)`. Početna strana nudi demo link ka `clients/nina22/`.

V3.3: kartice Izdvajamo bez popupa, usluge sa detaljima i CTA, video i galerija objekata sačuvani, PRE/POSLE spreman za stvarne fotografije.
